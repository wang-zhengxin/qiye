## 首次发布 / First release

- 在一个工作台展示当前浏览器用户资料中的多个窗口，管理真实标签、原生分组、休眠与关闭。
- 保存和恢复浏览会话，通过拖拽整理标签、会话与浏览器原生书签。
- 提供 9 个设置分区、77 项偏好，以及搜索、快照、回收站和导入导出。
- 支持可选的 WebDAV / GitHub Secret Gist 同步，连接凭据仅保存在本机。
- 提供独立的 Chromium、Firefox 和 Safari 转换源构建，以及中英文 README。
- 新增 GitHub 自动测试、分浏览器打包和版本标签触发的 Release 发布。

Qiye brings multiple browser windows, native tab groups, saved sessions, and bookmarks into one local-first workspace. This first release includes drag-and-drop organization, sleeping and closing tabs, configurable behavior, search, snapshots, recovery, import/export, and optional WebDAV or Secret Gist sync. Browser-specific builds, bilingual documentation, automated tests, and tag-triggered GitHub Releases are included.

### 当前边界 / Current limitations

- Chrome 中已保存但未打开的工具栏分组无法完整读取；打开后可管理并保存为会话。
- Firefox 附件为未签名临时测试构建；Safari 附件为转换源，尚无签名应用。
- 已执行自动测试和构建校验，尚未在全部目标浏览器中逐一安装实测。

Saved but closed Chrome toolbar groups cannot be fully read. Firefox packages are unsigned temporary test builds; Safari packages contain conversion source. Automated checks do not replace installation tests in each target browser.
