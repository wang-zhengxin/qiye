# 栖页 Qiye v1.5.1

- 拖动分栏边缘调整导航栏、内容区、暂存卡片和打开标签列表的尺寸，刷新后保留。支持双击、Home 键与顶部按钮恢复默认尺寸，方向键微调。
- 打开的标签支持栖页内自定义显示名，同一网址共用，留空恢复原标题；不修改网页或浏览器标签栏标题。已保存标签增加直接重命名入口，原生浏览器分组支持重命名。
- 修复标签较多时窗口卡片被压缩而裁切内容、无法滚动到末尾的问题；勾选或刷新后保留各列表滚动位置，短窗口仍可滚动访问操作区。
- 新增数据边界、名称恢复、原生接口、保存会话与本机尺寸持久化验证。

Open-tab custom names and pane sizes are device-local. Renaming a native group updates the browser group; renaming an open tab changes its Qiye display name only. No new browser permissions are required.
