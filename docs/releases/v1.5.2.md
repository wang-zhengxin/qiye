# 栖页 Qiye v1.5.2

- 工作台分栏可拖动调整宽高，自动保存尺寸；支持双击、Home 键和顶部按钮恢复默认。
- 打开的标签可设置栖页内自定义显示名，已保存标签及原生浏览器分组可重命名。
- 修复大量标签无法滚动到末尾的问题，勾选、刷新列表后保留滚动位置。
- 远端同步仅支持 HTTPS；旧 HTTP 配置也会在发出请求或凭据前被拒绝。已移除 HTTP 可选访问范围，不扩大现有 HTTPS 范围。
- Firefox 补充现有书签链接、偏好及搜索行为的数据类型声明；同步按功能申请授权，开始页搜索单独申请授权，拒绝时不发送。

Qiye now supports resizable panes, custom tab names, and independently scrolling long lists. Remote sync requires HTTPS. Firefox requests optional data-transmission consent separately for sync and start-page searches. Core local organization works without remote sync.

打开标签的自定义名称仅在栖页内显示。Firefox ZIP 为未签名的临时测试/商店提交包；普通用户请等待正式商店签名。Safari 包为转换源码，不能直接安装。本次 GitHub 下载发布不代表浏览器商店已上线。
