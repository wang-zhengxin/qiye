# Qiye Support

Free desktop tab and bookmark workspace · Version 1.5.2

Contact: wangzhengxin007@gmail.com

Report an issue: https://github.com/wang-zhengxin/qiye/issues

Click the extension icon or use Alt + Shift + T to open the workspace. Open tabs show the current browser profile's windows; saved sessions retain links for later. Extract developer ZIPs before loading them. Unsigned Firefox ZIPs are temporary test builds; normal installation requires a signed version.

Select tabs to save a session, stash, sleep or close them. Drag links to bookmark folders; dragging a saved session creates or reuses a named child folder. Items deleted through Qiye can be restored from its recycle bin; bookmarks deleted elsewhere do not appear there.

Export collections before switching from an unpacked build to a store build: extension IDs and storage may differ. Exports contain readable URLs and titles but no credentials. Import adds to existing saved content; preferences have separate import/export tools.

Sync is off by default. To use it, configure your own HTTPS WebDAV or Secret Gist, grant access, test the connection and perform a manual sync. Disable automatic sync, remove saved credentials or revoke provider tokens to stop connections. Delete remote files separately. Resetting preferences does not erase all data; uninstall or clear extension storage to remove complete local extension data. Native bookmarks remain owned by the browser.

For support, include browser, OS and Qiye versions, steps to reproduce, and a redacted screenshot. Do not send passwords, tokens or full private bookmark backups. See the browser support guide for capabilities and validation limits.
