Qiye — Tabs, Sessions & Bookmarks

Short description

Organize tabs across windows, save sessions, manage bookmarks, and put background tabs to sleep. Local-first and free.

Full description

Qiye is a free, local-first workspace for Microsoft Edge. Bring open tabs, native tab groups, saved sessions, and browser bookmarks into one place, then organize them with drag and drop.

MANAGE YOUR CURRENT BROWSING See tabs across windows in the current browser profile, switch to a page or window, reorder tabs, create native groups, and close tabs you no longer need. Put supported background tabs to sleep while keeping their tab-bar entries available. Active tabs are protected from sleeping.

SAVE A SESSION FOR LATER Keep a named set of links and reopen it when you are ready. Star, lock, clone, sort, and deduplicate saved sessions. Closing an open tab does not delete a saved session. Saved sessions and the current tab list serve different purposes.

ORGANIZE BOOKMARKS Work with the browser's real bookmarks and folders. Add, edit, and move items, including nested folders. Drag links to bookmark folders; dragging a saved session creates or reuses a named subfolder while retaining the source session. Built-in and managed folders are protected.

FIND AND RECOVER Search tabs and saved links, set items aside in a stash, create local snapshots, import and export collections, and recover items deleted through Qiye from its recycle bin.

MAKE THE WORKSPACE YOURS Drag pane separators to resize the workspace; sizes stay on this device. Give open tabs custom Qiye display names, rename saved tabs and native groups, and scroll long lists independently. Open-tab names do not modify website or browser tab-strip titles. Choose light, dark, or system appearance and use Chinese or English controls. 77 preferences across 9 sections cover saving, opening, display, search, shortcuts, context menus, and an optional start page.

LOCAL BY DEFAULT, OPTIONAL SYNC Core features work without a Qiye account or subscription. Collections and preferences stay in browser-local storage by default. You may connect your own WebDAV service or GitHub Secret Gist to sync saved sessions, stashed links, and selected preferences. Sync is off until configured. Network access is requested when you configure the service. Credentials are used to authenticate to your selected provider and are excluded from collection exports and synced preference data. Native bookmark-tree sync remains the browser's responsibility.

PLEASE NOTE This listing is for desktop Microsoft Edge. Native groups and sleeping depend on browser support. Saved but closed toolbar groups cannot be fully read; open a group first to manage it. Closed-tab history and a complete browsing history are not collected. Recently opened only records links opened through Qiye. A Secret Gist is unlisted, not end-to-end encrypted. Backups contain readable URLs and titles, so store them carefully. External sync services have their own terms and may charge for their service.
