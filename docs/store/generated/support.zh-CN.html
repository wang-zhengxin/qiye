栖页 Qiye 使用与支持

免费桌面标签与书签工作台 · 当前版本 1.5.0

支持邮箱：wangzhengxin007@gmail.com

问题反馈：https://github.com/wang-zhengxin/qiye/issues

开始使用

安装对应浏览器扩展后点击栖页图标，或按 Alt + Shift + T 打开工作台。“当前标签页”默认显示同一用户资料下的所有窗口；“已保存会话”保留网址以供稍后恢复。开发者 ZIP 需要先解压再加载。Firefox 未签名 ZIP 仅供临时测试，普通安装请使用已签名版本。

整理与恢复

选择标签可保存会话、暂存、休眠或关闭。将链接拖入书签文件夹可收藏，整组会话拖入会创建或复用同名子目录。会话可锁定以防误改，通过工作台删除的收藏可从回收站恢复。浏览器自身删除的书签不会进入栖页回收站。

备份与迁移

顶部“导出”生成收藏 JSON，导入会保留已有收藏并追加内容；偏好可在设置中单独导入导出。导出文件不含凭据，但含可读网址与标题。安装商店版本前先备份，开发者模式与商店版本可能使用不同扩展 ID，不应假定数据自动迁移。

同步与数据清除

默认关闭同步。需要时配置自己的 HTTPS WebDAV 或 GitHub Secret Gist，再保存授权、测试连接并手动同步。关闭自动同步、移除已保存凭据和撤销服务 Token 可停止连接；远端文件需自行删除。可在回收站、快照和最近访问中清除对应记录；仅重置偏好不会清除全部数据，完整清除请卸载或清除扩展存储。

反馈问题

请提供浏览器与系统版本、栖页版本、复现步骤和已遮挡敏感内容的截图。不要发送密码、Token 或完整私人书签备份。开发者尚未完成所有目标浏览器的真实安装验证，功能边界以浏览器支持文档为准。
