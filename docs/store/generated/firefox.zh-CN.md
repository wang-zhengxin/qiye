# 栖页 Qiye · 标签与书签工作台

简短说明

在一个工作台整理多窗口标签、原生分组与书签，保存会话、休眠后台标签，本地优先，免费使用。

详细说明

栖页 Qiye 是为 Mozilla Firefox 提供的免费、本地优先的标签与书签工作台。把打开的标签、浏览器原生分组、已保存会话和书签放在一个页面中，通过拖拽完成整理。

整理当前浏览现场
默认展示当前浏览器用户资料中的多个窗口，可切换到对应页面或窗口、调整标签顺序、创建原生分组、休眠后台标签或关闭不再需要的页面。休眠保留标签栏入口；正在使用的标签受到保护。

保存会话，随时继续
把一组网页保存为有名称的会话，之后批量重新打开。支持星标、锁定、克隆、去重与排序。打开的标签代表当前浏览现场，已保存会话用于持久保留网址；关闭原标签不会删除已保存会话。

直接管理浏览器书签
新增、编辑、移动真实书签与嵌套文件夹；将链接拖入文件夹即可收藏。把整组已保存会话拖入书签目录，会创建或复用同名子文件夹，原会话保留。浏览器内置或托管目录受到保护。

查找、暂存与恢复
搜索标签与收藏，把尚未整理的网址先放入暂存区。支持本地快照、收藏导入导出，以及恢复通过工作台删除的收藏内容。直接在浏览器其他界面删除的书签不进入栖页回收站。

按自己的习惯配置
拖动分栏边缘调整宽高，尺寸保存在本机；打开标签可设置栖页内显示名，已保存标签与原生分组可重命名，长列表支持独立滚动。打开标签的自定义名称不修改网页或浏览器标签栏标题。提供中文和英文主要操作界面、浅色、深色和跟随系统外观。9 个设置分区、77 项偏好涵盖保存与打开行为、显示、搜索、快捷键、右键菜单和可选开始页。

默认本地使用，可选连接自己的同步服务
核心功能无需栖页账号或订阅，默认在浏览器本机保存收藏与偏好。可自行连接 WebDAV 或 GitHub Secret Gist，同步已保存会话、暂存和部分偏好；配置前不会自动同步。仅在配置同步时申请对应站点访问。凭据用于所选服务的认证，不进入收藏导出或远端偏好正文。原生书签树的跨设备同步由浏览器自身管理。

使用范围与注意事项
本版本面向桌面 Mozilla Firefox；原生分组和休眠以实际接口能力为准。当前不能完整读取已保存但未打开的工具栏分组，需先打开该组。不会读取完整浏览历史，“最近访问”仅记录通过栖页打开的链接。Secret Gist 为不公开列出的文件，并非端到端加密；导出文件含可读的网址与标题，请妥善保存。外部同步服务由用户自行选择，可能有其自身费用。
