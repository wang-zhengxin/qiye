# 栖页 Qiye 审核操作说明

版本：1.5.2 · 免费 · 桌面浏览器 · 无栖页账号登录要求

支持邮箱：wangzhengxin007@gmail.com

## 提交内容与验证范围

Chromium 包用于 Chrome / Edge；Firefox 必须使用独立 Firefox 包。包根目录直接包含 manifest.json。Firefox 当前 Release ZIP 未签名，用于提交或临时测试，普通用户安装版本需要 Mozilla 签名。

现有自动测试覆盖模拟扩展接口与业务逻辑；材料中的截图来自真实工作台代码在隔离预览环境中的演示数据。它们不证明已在所有目标浏览器完成扩展安装或原生接口验收。请使用下面的步骤测试实际提交包。

## 核心功能复现

1. 在独立测试用户资料中安装扩展。点击扩展图标，或按 Alt + Shift + T，进入工作台。
2. 在两个或更多窗口打开测试页面。进入“当前标签页”，范围选择“所有窗口”。预期按窗口组织，每个标签在主列表中只出现一次；可切换“当前窗口”。
3. 选择两个测试标签，点击“新建分组”。预期浏览器创建真实标签组；可拖入已有组或解除分组。不要使用已保存但尚未打开的工具栏组来测试，公开接口无法完整读取它们。
4. 激活一个标签，尝试休眠另一个后台标签。后台标签可被浏览器丢弃，标签栏入口保留；激活后重新加载。当前活跃标签受到保护，特殊页面或浏览器自身限制可能使操作不可用。
5. 选择标签并“保存会话”。进入“已保存会话”，确认链接保留；关闭原标签后仍可恢复会话。默认保存不会关闭原标签；开启“保存成功后关闭”后先保存再关闭。
6. 将会话锁定，验证受保护的编辑或移动操作被阻止；解锁后可继续。测试星标、克隆、去重、排序及单组打开。
7. 在“浏览器书签”创建测试文件夹和书签，修改名称、移动位置。拖动链接到文件夹应创建书签；将整个保存会话拖入文件夹会创建或复用同名子目录，源会话保留。内置与托管文件夹不能随意删除、重命名或移动。
8. 通过工作台删除一个收藏或测试书签，再到“回收站”恢复；不要将浏览器其他界面删除的项目作为本功能测试对象。
9. 创建快照；导出收藏 JSON 并重新导入，验证现有收藏保留、导入内容追加。偏好使用设置页中独立的导入导出入口。
10. 切换语言或外观，点击“保存设置”，重新打开工作台确认保存。可选新标签页模式默认不替换浏览器页面。

## 可选同步测试

核心功能不依赖同步服务。默认 syncProvider=none、autoSync=false。项目没有供审核者登录的栖页服务端账号。

需要测试同步时，审核者可以使用自己的测试 WebDAV HTTPS 文件地址或可访问 Secret Gist 的测试 Token；请勿使用真实私人收藏。开发者不会在提交材料里嵌入长期有效私人凭据。如果平台要求专用测试服务，另行创建可撤销测试凭据并通过平台审核私密字段提供。

1. 在“同步配置”选择服务并填入地址及认证信息，保存并批准所选站点访问。Firefox 还需批准可选的数据传输同意。
2. 测试连接，再执行首次手动同步。连接测试以读取为主，不能单独证明写入权限；手动同步应实际创建或更新远端文件。Gist ID 留空时，首次成功创建会记录 ID。
3. 修改测试会话后再次同步，验证合并；执行覆盖拉取前应保留本地恢复快照。
4. 拒绝站点访问或在 Firefox 撤销数据传输同意，验证远端请求停止且本地内容保留。测试凭据失效、远端不可达及断网后的错误提示。
5. “移除已保存凭据”后自动同步关闭；远端文件保留，需在服务商处单独删除。

## 权限、数据与代码

- 权限逐项说明见 generated/permissions.md；当前清单无 history、scripting 或内容脚本。
- 不从远端加载执行代码；同步解析校验后的 JSON。依赖仅为浏览器接口与打包时的 Node.js 内置模块，扩展没有第三方运行依赖。
- 默认数据在浏览器本机；可选同步会传输会话标题、网址等及认证所需凭据。原生书签树不进入远端同步正文。
- 当前版本仅接受 HTTPS WebDAV；旧 HTTP 配置也会在发出请求及凭据前被拒绝，不跟随重定向。未实现端到端加密或应用级凭据加密。Firefox 同步按实际功能请求相关数据声明，偏好同步关闭时不请求 technicalAndInteraction；可选开始页提交搜索时单独请求 searchTerms，拒绝后不跳转。AMO 校验和签名以平台最终结果为准。
- 支持范围见 BROWSERS.md；Firefox 的内置数据传输分类和可选开始页搜索仍需结合 AMO 实际校验核对。

## 从源码重现 Firefox 包

环境：Node.js 20.11+，推荐与 CI 相同的 Node.js 24。无需 npm install。

```bash
node scripts/package.mjs --target=firefox
```

输出为 artifacts/qiye-workspace-firefox-v1.5.2.zip，根目录含 manifest.json；dist-firefox/ 为对应解压目录。构建过程只复制本地文件、生成目标清单并压缩，没有代码混淆或远程代码下载。
