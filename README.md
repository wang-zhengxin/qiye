# 栖页 Qiye · 书签与标签工作台

栖页 Qiye 是一个管理浏览器标签、分组与书签的本地工作台，按照用户提供的 [Figma 设计](https://www.figma.com/design/bWy9soamVKc057Z6MDjUz2/) 实现。使用原生 JavaScript、CSS 和 Manifest V3，不需要安装第三方运行依赖。

## 预览

需要 Node.js 20.11 或更高版本，在项目目录运行：

```bash
npm run dev
```

打开 http://127.0.0.1:4173 。普通网页使用独立的演示数据，保存在当前浏览器的 localStorage；不会读取或关闭你的真实浏览器标签。可在“设置 → 重置演示”恢复初始展示，重置前会为收藏和暂存创建快照。

## 管理真实标签和书签

```bash
npm run build
```

1. 在 Chrome 的扩展管理页（`chrome://extensions`）或 Edge 的扩展管理页（`edge://extensions`）开启开发者模式。
2. 选择“加载已解压的扩展程序”，选择本项目的 `dist` 目录。该目录内应直接包含 `manifest.json`，不要选择 ZIP 文件或项目上层目录。
3. 点击扩展按钮，或按 `Alt + Shift + T` 打开工作台。

详细步骤见 [安装说明](INSTALL.md)。运行 `npm run package` 会重新构建并生成根目录直接包含 `manifest.json` 的 ZIP；使用 ZIP 时请先解压，再选择解压后的扩展目录。

扩展首次启动使用空收藏，并读取真实标签页及浏览器支持的原生标签组和书签。扩展收藏使用浏览器扩展的本地存储保存，与网页演示相互独立。管理页自身不会出现在待处理标签列表。

## 已实现

- **当前标签**：默认展示所有窗口，按窗口与原生组分区、记住窗口范围、按窗口全选、定位窗口、实时更新、切换激活、休眠、唤醒、关闭、多选、保存为组、暂存。
- **浏览器原生分组**：创建、拖入分组、整组保存、整组休眠、整组关闭、解除分组。
- **收藏标签组**：新建、重命名、星标、锁定、展开折叠、整组重新打开为浏览器原生分组、休眠或关闭对应的已打开标签、删除恢复。
- **组内标签**：添加、编辑标题和网址、去重、删除恢复、移动到其他组、复制整组链接、收藏到浏览器书签。
- **拖动整理**：当前标签 → 收藏组/暂存/书签，收藏标签跨组移动、组内排序、拖动创建新组，标签组排序、整组存入浏览器书签文件夹，书签文件夹跨层级移动、书签移入文件夹或复制到标签组。
- **浏览器书签**：读取、新增、编辑、删除恢复、文件夹筛选、新建文件夹、拖动移动。
- **辅助功能**：名称和网址搜索、批量管理、卡片/列表视图、收藏与浏览现场快照、最近访问、本地导入导出、深色外观、紧凑布局。
- **配置中心**：9 个分区、77 项偏好，支持搜索设置、显式保存、分区重置、完整配置导入导出、回退到上次保存版本。详见 [配置说明](CONFIGURATION.md)。
- **扩展行为**：启动/新窗口打开工作台、固定工作台、恢复浏览现场、可配置右键菜单、图标数字、快捷面板、新标签转入开始页或工作台。
- **远端同步**：WebDAV / GitHub Secret Gist，合并推送、覆盖推送、拉取恢复、偏好同步、自动同步间隔与多个时间段。

“关闭”操作作用于浏览器中已打开的标签，收藏链接会保留；“删除”将收藏移入回收站。休眠调用 `tabs.discard`，页面留在标签栏，激活后重新加载。正在使用的标签不会被休眠。浏览器对部分特殊标签的休眠限制会显示为操作未完成。

锁定的收藏组不能删除、编辑或移动内容。收藏/暂存默认保留原标签，可在设置里开启保存成功后关闭；链接会先成功写入本地存储，再执行关闭。

## 导入、备份与同步范围

- 导出包含收藏标签组、暂存、浏览器书签及书签文件夹信息的 JSON，兼容读取旧版分类字段。
- 导入保留现有数据并添加收藏，支持本工具 JSON、包含 `groups`/`tabGroups` 和 `tabs`/`tabList` 的通用标签组 JSON，以及 OneTab 的 `网址 | 标题` 或制表符分隔文本。
- 导入的浏览器书签保存为“导入的浏览器书签”收藏组，避免未经选择批量改写原生书签。
- 回收站、访问记录、偏好和快照保存在本机，不包含在收藏导出中。快照恢复会补回缺失收藏，并将当时打开的标签保存为新组。
- 顶栏“同步”进入连接配置或执行已配置的远端同步；右侧刷新按钮重新读取浏览器标签。默认仅本地，选择服务并填写连接信息后才会同步。当前未提供 Toby/SessionBuddy 专有格式解析。
- 配置导出与收藏导出相互独立：配置文件包含 77 项偏好，不包含账号密码或 Token。导入配置不会改动收藏，并保持自动同步关闭，确认保存后生效。

## 书签替代分类（v1.2.0）

- 左侧直接显示浏览器书签文件夹树，可展开、创建子文件夹、重命名、移动及删除恢复。浏览器内置和托管文件夹受到保护。
- “已保存标签”保留标签组和会话恢复能力；不再使用独立分类。原分类与组的归属保存在“分类整合前的收藏”快照中，原链接、星标、锁定状态保留。
- 将标签或标签组拖到书签文件夹：复制链接到浏览器书签，标签组会创建或复用同名子文件夹。遵循重复链接设置，源标签组、已打开标签不会因保存为书签而删除或关闭。
- 拖动书签、书签文件夹：移动原生数据；禁止将文件夹移入自身或子孙文件夹。文件夹删除前先持久保存完整子树，若内容在此期间改变则停止删除；可从回收站恢复到原父文件夹，原父级不存在则恢复到可写根文件夹。
- 浏览器书签由浏览器原生同步管理，不进入 WebDAV / Gist 会话同步。网页预览只操作演示书签；真实书签需要加载扩展。
- 本次新增验证覆盖原生文件夹 API、嵌套恢复、并发删除保护、复制失败回滚、重复链接及旧数据迁移。

## 项目标识与升级（v1.3.0）

项目名称为“栖页 Qiye”，包名为 `qiye-workspace`。工作台、快捷面板、开始页和扩展图标使用统一标识，导出文件与同步数据使用 `qiye` 命名。

旧版本地数据会先复制到新命名空间，确认写入成功后再移除旧存储键，保留收藏标识、分组、快照、设置与凭据。旧版配置和同步格式仍可读取。历史示例中的原项目名称与仓库链接会更新，其他收藏链接保留。已有 WebDAV 地址与 Gist 文件位置不会擅自更改，新建 Gist 使用 `qiye-workspace.json`。

`assets/brand/` 中的 SVG 与扩展 PNG 图标为本项目绘制，沿用设计中的暖色。旧版生成截图与压缩包已由本次输出替换。

## 所有窗口的标签（v1.4.0）

默认展示同一 Chrome / Edge 用户资料下所有已打开窗口的标签，按窗口分区，并在窗口内保留原生标签组和浏览器中的顺序。工作台自身的扩展页面不计入待管理标签。窗口、分组和标签发生变化时自动更新。

右侧面板和“当前标签页”主列表均可切换“所有窗口 / 当前窗口”，选择会自动保存，也可在“设置 → 展示配置 → 打开标签的窗口范围”中调整。支持按窗口全选、跨窗口批量操作、点击标签定位原窗口，以及跨窗口拖动标签。网页预览提供三个窗口的演示数据，不会读取真实浏览器标签。

读取范围由浏览器当前用户资料与已授予的访问权限决定，不跨其他 Chrome 用户资料或其他浏览器实例。

## 标签列表去重（v1.4.1）

“当前标签页”使用完整宽度的主列表，按窗口和 Chrome 原生分组展示，每个打开的标签只出现一次。全局搜索同样隐藏重复的右侧列表。书签和已保存会话页面仍提供右侧标签区，方便拖拽收藏；其显示开关继续生效。

原“已保存标签”入口改名为“已保存会话”，明确其用于保存和恢复浏览会话，与实时打开的浏览器标签独立。已有数据、分组和浏览器标签保持原样。主列表保留刷新、暂存、保存会话、休眠与关闭操作。

## 主流浏览器适配（v1.5.0）

支持桌面 Chrome、Edge、Brave、Opera、Vivaldi 的 Chromium 通用构建，并新增 Firefox 140+ 专用构建。Firefox 使用原生 Promise 接口、模块后台脚本和稳定扩展标识，书签目录适配其根节点与分隔线。缺少分组、休眠或书签接口时，工作台继续运行，相应功能停用并解释原因。

`npm run build` 生成 `dist/`、`dist-firefox/`、`dist-safari/`；`npm run package` 生成对应的三个 ZIP，清单文件均位于包根目录。Safari 当前仅提供转换源，需完整 Xcode 和签名流程才能生成可安装的应用，且原生书签、分组和休眠仍受浏览器接口限制。Firefox 当前为未签名临时测试包。详见 [浏览器支持与验证范围](BROWSERS.md) 和 [安装说明](INSTALL.md)。
